# pushkar.github.io

Personal portfolio website built with plain HTML, CSS, and JavaScript.

## Features

- Dark-themed, responsive single-page design
- Smooth scroll-reveal animations
- Mobile-friendly navigation
- Blog system with standalone HTML posts
- Contact form via Formspree
- Accessible (keyboard navigation, ARIA, reduced-motion support)

## Getting Started

Open `index.html` in a browser, or visit [pushkar.github.io](https://pushkar.github.io).

## Adding a Blog Post

1. Copy `blog/template.html` to `blog/posts/your-post-title.html`
2. Update the title, meta description, date, and content
3. Add a card for the post in `blog/index.html` and `index.html` (blog section)

## Customization

Edit CSS custom properties in `css/style.css` under `:root` to change colors, fonts, and spacing. Replace the Formspree form action URL in `index.html` with your own.
