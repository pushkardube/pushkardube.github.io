My First Blog Post

Published on February 15, 2026 · 3 min read

Welcome to my blog! I'm excited to finally have a space where I can share my thoughts, document what I'm learning, and hopefully help others along the way.

Why I Started This Blog

As a student developer, I'm constantly learning new things — whether it's a new programming language, a framework, or a concept in computer science. I realized that one of the best ways to solidify my understanding is to write about it.

This blog is my way of "learning in public." By putting my thoughts out there, I hope to connect with other developers, get feedback, and contribute to the community that has taught me so much.

What to Expect

Here's what you'll find on this blog:

  • Tutorials — Step-by-step guides on topics I've figured out
  • Project walkthroughs — Behind-the-scenes looks at things I'm building
  • Learning notes — Summaries of concepts I'm studying
  • Reflections — Thoughts on the developer journey as a student

Building This Site

This portfolio and blog were built entirely with plain HTML, CSS, and JavaScript — no frameworks, no build tools. I wanted to keep things simple, fast, and easy to maintain. Here are some of the key features:

  • Dark theme with CSS custom properties for easy customization
  • Responsive design that works on all screen sizes
  • Smooth scroll-reveal animations using IntersectionObserver
  • Accessible navigation with keyboard support
  • A simple blog system with standalone HTML pages

"The best time to start writing is now. The second best time is also now."

What's Next

I have a lot of ideas for upcoming posts. Stay tuned for tutorials on CSS Grid, JavaScript tips, and project breakdowns. If you have any topics you'd like me to cover, feel free to reach out!

Thanks for stopping by, and happy coding!
